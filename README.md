## 🔧 常用Git命令

```bash
# 初始化仓库
git init

# 添加文件到暂存区
git add .
git add filename.txt

# 提交更改
git commit -m "提交信息"

# 查看状态
git status

# 查看提交历史
git log

# 创建分支
git branch feature-name

# 切换分支
git checkout feature-name

# 合并分支
git merge feature-name

# 推送到远程仓库
git push origin main

# 拉取最新更改
git pull origin main
```
